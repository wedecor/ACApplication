Every modern washing machine reports faults as 2- or 3-character codes.
Here is the canonical reference for the four most common Indian-market
brands.

## LG

| Code | Meaning | Try this |
| --- | --- | --- |
| **OE** | Drain error | Clean drain pump filter; check outflow pipe. |
| **UE** | Unbalanced load | Redistribute heavy items (jeans, bedsheets). |
| **IE** | Inlet error | Confirm tap open + hose not kinked. |
| **DE** | Door not locking | Wipe gasket; press door firmly; check latch. |
| **PE** | Water-level sensor | Call a technician — pressure switch fault. |
| **LE** | Motor lock | Switch off mains for 5 minutes; if persists, motor failure. |

## Samsung

| Code | Meaning | Try this |
| --- | --- | --- |
| **4E** | Water supply | Tap fully open? Hose kink? Inlet filter clean? |
| **5E** | Drain error | Clean drain pump filter at bottom-front. |
| **UE / UB** | Unbalanced load | Reduce load; redistribute. |
| **dE / dC** | Door fault | Wipe door seal; ensure firm close. |
| **HE** | Heater fault | Service call — element burnt out. |
| **3E** | Motor RPM | Power off 15 min; if persists → motor / belt. |

## IFB

| Code | Meaning | Try this |
| --- | --- | --- |
| **E01** | Door open / latch failure | Push door firmly; clean gasket. |
| **E02** | Water inlet | Tap open? Inlet hose clear? |
| **E03** | Heating | Service call. |
| **E04** | Temperature sensor | Service call. |
| **E11** | Drain pump | Clean filter; check pipe. |
| **E13** | Motor / belt fault | Service call. |

## Whirlpool

| Code | Meaning | Try this |
| --- | --- | --- |
| **F03** | Heater sensor | Service call. |
| **F08** | Heater | Service call — element fault. |
| **F09** | Overflow | Inlet valve stuck open — service call. |
| **F11** | Communication | Power-cycle; if persists, service. |

## When to power-cycle vs. when to call

For codes triggered by **transient conditions** — unbalanced loads, soft
door-latch misalignments, supply-tap issues — a 5-minute power-cycle
(switch off at the wall) usually clears them. For codes pointing at
**hardware** (motor, heater, sensor, PCB) call a technician — running
the machine through repeated power cycles can damage the controller.
