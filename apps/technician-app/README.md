# @ac/technician-app

Expo Router (React Native) field app for technicians. Foundation only.

## Run

```bash
pnpm --filter @ac/technician-app dev    # opens Expo Dev Tools
pnpm --filter @ac/technician-app ios
pnpm --filter @ac/technician-app android
```

## Planned features

- Phone + OTP auth (shared with API)
- Today's jobs queue
- Live route + ETA broadcast
- Offline job completion
- Push notifications via Expo Notifications
